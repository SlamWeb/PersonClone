# Study 1 实验协议 V2

## 1. 研究目标

Study 1 研究的问题是：

> 哪些特征会让 LLM 生成的回答听起来更像目标作者本人？

本实验测量的是“特定作者相似性”，不是一般意义上的文字自然度，也不是单纯判断文本是否由 AI 生成。

实验固定为 `2 篇单篇判断 + 阶段过渡 + 2 组同题比较`。四道题互不重复，目标完成时间不超过 30 分钟。

## 2. 第一阶段冻结协议

每篇匿名回答按以下顺序完成：

1. 阅读问题与回答；
2. 给整篇作者相似度打 `-2～+2` 分；
3. 自由标注 `1～6` 处互不重叠的文字；
4. 每处标注填写 `-2～+2` 的影响分和一条简短理由；
5. 填写整篇最关键的判断理由。

整体分锚点为：`-2 明显不像`、`-1 比较不像`、`0 拿不准`、`+1 比较像`、`+2 明显像`。
划线影响分锚点为：`-2 明显降低相似感`、`-1 略微降低`、`0 方向不明确`、`+1 略微提高`、`+2 明显提高`。

整体分和划线分彼此独立，不做相乘，也不要求方向一致。参与者可以在提交前自由修改整体分、划线和理由；最终提交值进入主要分析，修改过程只用于质量检查。

完成两篇单篇后，必须展示独立过渡页。过渡页只解释第二部分是同题双篇比较，不披露材料来源；参与者确认后才进入第二阶段。

## 3. 第二阶段冻结协议

### 2.1 任务组成

每位参与者完成两组匿名同题比较：

1. `AI vs 作者原回答`：观察生成回答与作者本人之间的可辨别性。
2. `AI vs AI`：比较两种生成方法在作者相似性上的相对表现。

两组比较使用不同问题，也不与第一阶段重复。回答来源、生成方法和正确身份对参与者隐藏。A/B 位置和两组题目顺序按参与者稳定随机，刷新后不得变化。三个 AI 系统按 cohort 平衡轮换：每位参与者恰好看到三个不同 AI 系统，一个与 Gold 比较，另外两个互相比较。

### 2.2 每组任务

参与者依次完成四项内容：

1. **选择更像作者的一篇**
   - 回答 A
   - 回答 B
   - 不提供平局或“无法区分”。

2. **报告判断信心**
   - 两篇比较接近
   - 有一定把握
   - 非常确定

3. **填写最关键的选择理由**
   - 提示语：`你选择这篇最关键的理由是什么？`
   - 必填。
   - 只要求一个最关键因素，一句话即可。

4. **填写最关键的不选择理由**
   - 提示语：`另一篇让你没有选择它的最关键原因是什么？`
   - 必填。
   - 只要求一个最关键因素，一句话即可。

第二阶段不提供划线标注，不再询问“其他区别”，也不要求参与者用“一对相反的说法”概括。参与者界面不展示 feature 示例，避免诱导其判断依据。

### 2.3 作答顺序

页面交互顺序固定为：

```text
选择 A/B
-> 立即报告信心
-> 填写选择理由
-> 填写不选择理由
-> 提交本组判断
```

信心应在开放理由之前记录，减少参与者为了让后续解释显得合理而事后调整信心的影响。

## 4. 结束与既往接触

四道题完成后只进行一次全局既往接触检查：`没看过 / 不确定 / 看过`。随后统一提交正式任务。三轮自由体验和开放反馈属于探索性数据，不进入 Study 1 的主要 feature 分析。

## 5. 信心的分析边界

信心描述的是本次相对判断的区分强度，不等于 feature 的贡献大小，也不改变两个理由的填写要求。

主分析不得使用任意系数把理由出现次数与信心分数直接相乘。建议按以下顺序分析：

1. 所有回答等权进入 feature 编码和提及率统计。
2. 按三个信心层级分别报告 feature 分布。
3. 比较全体结果与排除“两篇比较接近”后的结果，作为稳健性检查。
4. 观察哪些 feature 经常伴随高信心选择或高信心排除，但不把这种共现直接解释为因果贡献。

低信心记录不得删除。它们反映两篇材料接近、线索较弱或参与者难以区分，同样属于有效实验结果。

## 6. 理由编码

理由编码必须把“特征维度”和“具体表现”分开。不能把“观点违背作者”或“句子太长”直接当作 feature 名称。

每条理由至少记录：

```text
feature_dimension     特征维度
feature_realization   具体表现或方向
evidence_role         选择理由 / 不选择理由
confidence            判断信心
author_id             目标作者
trial_id              实验题目
```

示例：

| 特征维度 | 具体表现 | 判断作用 |
|---|---|---|
| 立场与观点 | 核心观点符合作者 | 选择理由 |
| 立场与观点 | 核心观点违背作者 | 不选择理由 |
| 句子长度 | 短句密集 | 选择理由 |
| 句子长度 | 句子过长 | 不选择理由 |
| 语气姿态 | 直接、确定 | 选择理由 |
| 语气姿态 | 过度温和、平衡 | 不选择理由 |

研究结果首先在特征维度层面聚合，再保留具体表现解释方向。跨作者结论应表述为“是否匹配目标作者的稳定习惯”，不能把某一种具体表现错误地概括成对所有作者都成立的规则。

初始编码框架可以参考以下上位维度，但这些维度不得展示给参与者：

1. 立场与世界观；
2. 论证方式；
3. 词汇与语域；
4. 语气与人格姿态；
5. 句法与节奏；
6. 自然度与 AI 痕迹。

编码阶段允许根据参与者理由补充或合并子类，并保留原始理由，确保研究者可以回溯编码依据。

## 7. 主要产出与分析边界

第一阶段至少报告整体相似度分布、feature 提及率、正负方向、影响强度、成为整篇关键理由的比例，以及跨作者、问题和材料来源的覆盖率。整体分是结果变量，划线是解释证据，不允许通过任意乘法构造“贡献分”。

第二阶段至少报告：

- `AI vs 作者原回答` 中各来源被选择为更像作者的比例；
- `AI vs AI` 中两种生成方法的相对胜率；
- 选择理由与不选择理由中的 feature 维度提及率；
- 每个 feature 维度的具体表现和方向；
- 每个 feature 维度在不同信心层级中的分布；
- 排除低信心判断后的稳健性结果。

第二阶段用于发现具有辨别力的线索并比较材料，不单独证明某个 feature 对作者相似性具有因果贡献。feature 的因果贡献留给后续受控生成与消融实验验证。
